# FolderCheck

Compare two sets of files or folders side by side — size, file count, subfolder count, per-file diff (added / removed / modified), timestamps, extension breakdown, optional SHA-256 content check.

Cross-platform: macOS, Windows, Linux. Written in Python + Tkinter.

## Run

```bash
python3 foldercheck.py
```

On macOS with Homebrew Python you may need Tk:

```bash
brew install python-tk@3.14   # match your python3 --version
```

## Features

- Add multiple files and/or folders to each of Side A and Side B
- Aggregated totals (size, files, subfolders, largest file)
- Per-file diff view with **added**, **removed**, **modified**, **unchanged** filters
- Timestamps (A modified / B modified / Newer)
- "Deep compare" toggle — hashes same-size files to detect content changes
- CSV export of the diff
- Live "Scanning…" popup with progress
- macOS `.app`, Windows `.exe`, Linux binary via PyInstaller (see build scripts)

## Download prebuilt binaries

Every push to `main` triggers a CI build. Grab the latest binaries from the
**Actions** tab → most recent run → **Artifacts** section, or from a tagged
release on the **Releases** page.

## Cutting a release

Tag a commit with a `v*` name and push the tag — GitHub Actions will build
macOS / Windows / Linux binaries and attach them to a new Release with
auto-generated release notes:

```bash
git tag v1.0.0
git push origin v1.0.0
```

## Build a standalone app locally

```bash
# macOS (.app)
python3 -m PyInstaller --windowed --name FolderCheck --icon icon/FolderCheck.icns foldercheck.py

# Windows (.exe)
build_windows.bat

# Linux
./build_linux.sh
```

Icons are generated by `python3 build_icon.py`.
